# Creating-home-lab-using-VirtualBox
This repository helps setup your VirtualBox and create virtual machines for home labs!

## Step 1 - Download VirtualBox (VB) 
Thanks to technology of VirtualBox we can create more virtual machines on our computer with minimal configuration. 
For more information look here: https://www.geeksforgeeks.org/cloud-computing/what-is-virtualbox/

Now it's time to install our VirtualBox at: https://www.virtualbox.org/wiki/Downloads
you will find download links for your operating system.  
//SS PLACE #1  
After download, installing it is fairly easy just continue with installation by clicking next, then install and you are all set with VB for now.  
//SS PLACE #2
## Step 2 - ISO images Linux/Windows
Now for ISO images most popular operating systems are Linux and Windows so we will focus on those:
 - Linux have a lot of distributions so we will cover only Ubuntu latest version but process of installation different distros look similar - you can get ISO image of Ubuntu here: https://ubuntu.com/download/desktop
<ssPLACE#3>
 - Windows have a different type of installation so firstly we need to download Media Creation Tool at https://www.microsoft.com/en-us/software-download/windows10  
<ssPLACE#4>
Now we can launch the application and choose ISO image and then which version of Windows to choose.
<ssPLAce#5>  
I will choose Windows 10 after that we just continue installation and we should get our ISO.
## Step 3 - Creating virtual machines on VB
Now we can start your VB and start to create our first virtual machines!

 We click new  
  <ssPLACE#6>  
  Then you can see few options as VM name or folder we will focus on ISO image.  
  <ssPLACE#7>  
  I will choose for my first system a Windows, click arrow on right side  
  <ssPLACE#7>  
  And then click other and search for Windows and select it  
  <ssPLACE#8>  
  Now check Proceed with Unattended Installation  
  <ssPLACE#9>  
  After that we will go to OS installation  
  <ssPLACE#10>  
  Here we have few more options:  
  User name - name of created user on VM  
  Password - password to log on user  
  You can type whatever you like I will choose something simple like Windows  
  <ssPLACE#11>  
  Next is hardware of machines and disc space **check Requirements tab below for that information.**  
  <ssPLACE#12>  
  Press finish and you are all set with VM let VirtualBox take care of installation for you. With Ubuntu it's the same process as with Windows.
  ## Step 4 - Enjoy your home lab  
  Thank you for reading my tutorial I hope it helped you and have fun at your home lab!

Set your VM with **recommended requirements** when creating new machines for better performance.  
Ubuntu: https://phoenixnap.com/kb/ubuntu-system-requirements  
Windows: https://support.microsoft.com/en-us/windows/experience/windows-10-system-requirements
