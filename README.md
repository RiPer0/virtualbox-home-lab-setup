# Creating-home-lab-using-VirtualBox
This repo is step by step guide showing how to create your first home lab with VirtualBox.

## Step 1 - Download VirtualBox 
Thanks to technology of VirtualBox we can create more operating systems on our machines with minimal configuration. 
For more information look here: https://www.geeksforgeeks.org/cloud-computing/what-is-virtualbox/

Now it's time to install our VirtualBox at: https://www.virtualbox.org/wiki/Downloads
you will find download links for your operating system.
